RSS for the OEIS

by Peter Kagey (2025-10-25)

I've added an RSS feed to my site that allows you to subscribe to a search in the On-Line Encyclopedia of Integer Sequences (OEIS). For example, if you want to subscribe to an RSS feed of all of my latest sequences, just add this to your feed reader:

https://api.peterkagey.com/oeis_feed.xml?q=author%3Akagey

Here's how it works: Go to the OEIS, and make a search, such as author:don,knuth. (It may be helpful to know about the OEIS search hints.)

If you look at the URL on the OEIS, you should see something like this

https://oeis.org/search?q=author%3Adon%2Cknuth&language=english&go=Search

select everything after the q= but before the &language, and paste that at the end of my new API endpoint:

https://api.peterkagey.com/oeis_feed.xml?q=author%3Adon%2Cknuth

Subscribe using your favorite RSS reader (I use feeder.co) and get updates every time a new sequence is added that matches your search criteria.

Under the hood

The RSS works by searching the OEIS using the fmt=json query param, and then doing a conversion of the JSON into RSS-compatible XML.

I have added the sort=created to return sequences in order of how recently they were added to the OEIS.

I have also sanitized the searches to only allow letters, numbers, spaces, and ,, :, -, ', _, and ".

Previous RSS on the OEIS

Russ Cox, the president of the OEIS has a "to do" item to "add recent new sequences RSS feed". If you want this, you can now add it with https://api.peterkagey.com/oeis_feed.xml?q=keyword%3Anew—but with roughly 34 new sequences added each day, this feed will be chatty!

Eight years ago, I had made a similar RSS feed, but it broke a few years ago when I migrated my website. I've added redirects for those old feeds to the new API, so that if you were using it before, it should be working again.

If you spot a bug or if there's a feature you want, let me know on Bluesky @peterkagey.com.
