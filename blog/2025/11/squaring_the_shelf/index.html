Squaring the shelf

by Peter Kagey (2025-11-12)

I've been working on designing and building a shelf based on the squaring the square problem, which appeared in Martin Gardner's November 1958 Mathematical Games column. The puzzle asks if it is possible to cut a square into smaller squares such such every smaller square is a different size.

The shelf I designed uses a solution to this puzzle to make several shelves of varying sizes and depths. Each square is extended out to a cube to create depth and dimension (and more room for my tchotchkes!) Below is a photo of a prototype along with a 3D model I created of the shelf, which you can drag around to see from any angle you'd like!

Prototyping

To build the prototype, I used a laser cutter to the walls out of cardboard boxes. I then used painters tape and super glue (cyanoacrylate) to secure the joints that most wanted to separate.

Build one yourself!

You can build one yourself either by laser cutting or 3D printing the walls. (Download a .zip file containing all .svg files or all .stl files.)

Python code

import svg

class WallBuilderSVG():
  MATERIAL_THICKNESS=1
  HOLE_HEIGHT=5

  def __init__(self, heights, joints):
    self.heights = heights
    self.joints = joints

  def svg_walls(self):
    t = self.MATERIAL_THICKNESS/2
    vertices = [(-t, 0),(-t, self.heights[0][1])]
    a = 0
    for i in range(1,len(self.heights)):
      (del_a, b0) = self.heights[i-1]
      (_, b1) = self.heights[i]
      a += del_a
      d = t if b0 > b1 else -t
      vertices.append((a+d, b0))
      vertices.append((a+d, b1))

    (del_a, b) = self.heights[-1]
    a += del_a
    vertices.append((a+t, b))
    vertices.append((a+t, 0))
    return svg.Polygon(points=vertices)

  def z_holes(self, hole_data):
    (a, z_max) = hole_data
    hole_list = []
    t = self.MATERIAL_THICKNESS/2
    start = 0 if self.IS_HORIZONTAL else self.HOLE_HEIGHT
    for z in range(start, z_max, 2*self.HOLE_HEIGHT):
      z0 = min(z_max, z + self.HOLE_HEIGHT)
      hole_list.append(svg.Polygon(points=[(a-t,z),(a+t,z),(a+t,z0),(a-t,z0)]))
    return hole_list

  def name(self, name):
    return [svg.Text(stroke="#F0F", text=name[5:],font_size=3,x=2,y=3,font_family="Courier")]

  def joint_holes(self):
    return map(self.z_holes, self.joints)

  def svg_export(self,file_name):
    elements = [self.svg_walls()]
    elements += self.joint_holes()
    elements += self.name(file_name)

    canvas = svg.SVG(
      width=120,
      height=120,
      style="fill: none; stroke: #00F; stroke-width: 0.1;",
      elements=elements,
      viewBox="-5 -5 120 120"
    )

    with open(f"svgs/{file_name}.svg", "w") as f:
      f.write(canvas.as_str())

OpenSCAD code

function filePath(nameStr) = str(nameStr, ".svg");

TH = 1;

module xWall(wallNumber, xDel, yDel, height) {
translate([xDel-TH/2,yDel,height])
rotate([-90,0,0])
translate([0, 0, -TH/2])
linear_extrude(TH)
import(filePath(str("x_", wallNumber)), dpi=254);
}

module yWall(wallNumber, xDel, yDel, height) {
translate([xDel,yDel-TH/2,height])
rotate([-90,0,90])
translate([0, 0, -TH/2])
linear_extrude(TH)
import(filePath(str("y_", wallNumber)), dpi=254);
}
