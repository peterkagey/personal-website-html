← Problem 133 →

Suppose we have a total order of some finite set of combinatorial objects, for example permutations, derangements, labeled graphs, partitions, compositions, Dyck paths, set partitions, signed partitions, labeled trees, etc.

Index the objects so that the minimum in the total order is indexed \(1\), the next element is indexed \(2\), and so on, up to the maximum which is labeled \(N\), the size of the set.

Question

What combinatorial objects have efficient ranking and unranking algorithms, and what are the algorithms?

Related questions

  1. In particular, when do objects that are counted with the principle of inclusion--exclusion have such algorithms? With Burnside's lemma?
  2. For which permutation statistics \(\operatorname{st}\colon S_n \to \mathbb Z\) is it possible to unrank the set \(\{\pi \in S_n \mid \operatorname{st}(\pi) = k\}\) for a given value of \(k\)?

Note

If we have two sets \(X\) and \(Y\) with an (efficient) bijection \(X \to Y\), a total order on \(X\) which induces a total order on \(Y\), and efficient ranking/unranking algorithms for \(X\), then we have efficient ranking/unranking algorithms for \(Y\). For instance, if we order labeled trees by lexicographic order of their Prüfer codes, then we have efficient ranking/unranking for labeled trees under this ordering.
