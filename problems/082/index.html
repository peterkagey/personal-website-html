How many functions fn,k:P([k])∖∅→{0,1,2,…,n} exist such that there is a sequence of finite sets (A1,A2,…,Ak) satisfying f(S)=#⋂i∈SAi for all S∈P([k])∖∅?

For example, when n=1 and k=3 there are fifteen such functions.

Question

How many such functions exist? Equivalently, how many ways are there to fill in a k-"base set" Venn diagram with integers such that no base set has more than n elements?

Related questions

  1. What if #Ai=#Aj for all i,j?
  2. What if Ai⊄Aj for all i≠j?
  3. What if this is done with unordered sets? (e.g. some functions in the example would be considered equivalent.)
  4. What if the corresponding diagrams need to be realizable as grid rectangles with areas corresponding to the table values?
  5. What if this is done with set union instead of set intersection?
