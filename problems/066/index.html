The number of ways to draw a triangle on a triangular grid is given by ∑k=1n−1k⋅t(n−k)=(n+24)=A000332(n−2) where t(m) is the m-th triangular number and \href="https://oeis.org/A000332">A000332 is a figurate number based on the 4-simplex.

The number of ways to draw a square on a square grid is given by ∑k=1n−1k⋅(n−k)2=16(n22)=n2(n2−112)=A002415(n) where \href="https://oeis.org/A002415">A002415 is a figurate number based on the 4-dimensional pyramid.

The number of ways to draw a hexagon on a centered hexagonal grid is given by ∑k=1n−1k⋅h(n−k)=(n(n+1)2)2=A000537(n−1), where h(m)= A003215(m) is the m-th centered hexagonal number.

Question

Is there a combinatorial explanation for why these numbers relate to 4-dimensional polytopes?
