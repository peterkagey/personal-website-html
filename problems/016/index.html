Let a3(n) be the least k>n such that nk or nk2 is a cube, and let A299117 be the image of a3(n).

Question

Is there another way to characterize what integers are in A299117?

Note

  • The function a3 is injective.
  • A299117 contains every cube, since a3(n3)=(n+1)3.

Yes. Write each positive integer by its prime factorization and classify primes according to the residue class of their exponent modulo 3. For an integer m, let the unordered pair (P1(m),P2(m)) record the set of primes whose exponents in m are congruent to 1(mod3) and to 2(mod3), respectively. Two integers m and n lie in the same equivalence class precisely when these unordered pairs agree. If m and n are equivalent then either mn or mn2 is a cube, and if they are not equivalent neither product is a cube. Thus a3(n) is simply the next larger integer in n's equivalence class, so the image A299117 is the set of integers that are not the smallest element of their class.

Consequences: every square lies in A299117 (its square root is a smaller member of the same class), while every squarefree number is minimal in its class and so does not lie in A299117.
