Given some set of functions {pi:[n]→[k]}i=1m, consider the semigroup generated by ⟨p1,p2,…,pm⟩.

Question

If the pis are chosen uniformly at random, what is the expected size of the semigroup ⟨p1,p2,…,pm⟩?

Related questions

  1. What's the expected number of functions m such that |⟨p1,p2,…,pm⟩|=kn? The minimum number of functions?
  2. What is the largest semigroup as a function of n, k, and m?
  3. Can you make any size semigroup with the right parameters? If not, what sizes can you make?
